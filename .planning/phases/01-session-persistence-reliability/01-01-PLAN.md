<objective>
Stand up the project's first-ever automated test infrastructure: two new xUnit v3 test projects (`Omphalos.UnitTests` for fast, no-DB logic tests; `Omphalos.IntegrationTests` for real-Postgres repository tests via Testcontainers), a shared Postgres container fixture, and a `dotnet test` CI gate. This is the Wave 0 test harness required by `01-VALIDATION.md` — it is the enabling infrastructure the backend persistence fix (Plan 02) writes its RED→GREEN tests against, and it satisfies decisions D-04 (add first test project, xUnit) and D-05 (wire tests into CI).

Purpose: Zero test infrastructure exists in this repo today (`.planning/codebase/CONCERNS.md`). Without a harness, the PERSIST-01/PERSIST-03 fixes cannot be guarded by tests, and the two bugs could silently regress. The integration project must use a real Postgres container (not EF InMemory/SQLite) because the core bug lives in Npgsql-specific `jsonb` (`PrepData`/`SessionLog`) round-tripping, which fake providers do not exercise.

Output: `Omphalos.UnitTests` + `Omphalos.IntegrationTests` projects registered in `Omphalos.slnx`, `PostgresFixture.cs` (shared container), a green smoke test proving the harness works end-to-end, and a `dotnet test` step in CI.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build/CI → NuGet registry | New third-party test packages are pulled during restore; a malicious/typosquatted package would execute in the build environment |
| test host → Docker daemon | Testcontainers launches a real container; the image tag must be a trusted, pinned official image |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | NuGet test-package installs (xunit.v3, xunit.runner.visualstudio, Microsoft.NET.Test.Sdk, Testcontainers.PostgreSql) | high | mitigate | All 4 packages were manually verified against nuget.org in RESEARCH.md's Package Legitimacy Audit — every one is a long-established, high-adoption, officially-published package (xunit.net, Microsoft, Testcontainers org); none flagged `[SUS]` or `[SLOP]`, so no `[ASSUMED]`/`[SUS]` package remains that would require a blocking human-verify checkpoint. Pin exact versions (3.2.2 / 3.1.5 / 18.7.0 / 4.13.0) in the `.csproj` files; do not float versions. |
| T-01-IMG | Tampering | Testcontainers Postgres image | low | accept | Fixture pins `postgres:17`, the same official image already used by `docker-compose.yml`; no new untrusted image is introduced. |
