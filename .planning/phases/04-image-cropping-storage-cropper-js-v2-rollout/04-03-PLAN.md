<route_contract>
- `GET /api/sessions/{sessionId}/characters/{id}/portrait/{variant}` (variant = original|cropped) — session-owned
- `GET /api/sessions/{sessionId}/locations/{id}/image/{variant}` — session-owned
- `GET /api/characters/{id}/portrait/{variant}` — GlobalCharacter (no ownership)
- `GET /api/locations/{id}/image/{variant}` — GlobalLocation (no ownership)

`/original` serves `OriginalImageData` (404 if null). `/cropped` serves `CroppedImageData ?? OriginalImageData` (404 if both null) — the display fallback (IMG-03).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> new image GET endpoints | Any authenticated user can request an image URL by id; ownership must be enforced server-side |
| client -> image write (Global create/update, session upsert) | User-supplied image bytes cross into storage |
| browser cache <- Cache-Control header | Shared vs per-user cacheability of served images |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Elevation of Privilege / Information Disclosure (IDOR) | Session Character/Location image GET endpoints | high | mitigate | Ownership enforced in the repository query (`c.Session.UserId == userId` / `l.Session.UserId == userId`), not id-only; cross-user test asserts 404 |
| T-04-02 | Denial of Service / Tampering | Image upload (Global create/update, session upsert) | high | mitigate | Server-side `ImageValidation.IsRecognizedImage` (magic-byte) + `MaxImageBytes` length check at the write endpoints -> 400; Kestrel 30MB body limit as backstop |
| T-04-03 | Tampering (MIME spoofing) | Content-Type of served images | medium | mitigate | `DetectImageMimeType` magic-byte sniff on the read path reflects real bytes regardless of client-declared type (D-09) |
| T-04-04 | Information Disclosure (cross-user cache poisoning) | Cache-Control on session-scoped images | medium | mitigate | `private` Cache-Control for session-scoped Character/Location images; `public` only for non-user-scoped Global* images |
| T-04-SC | Tampering | No new package with executable install in this plan (`Microsoft.AspNetCore.Mvc.Testing` is a first-party test-only package) | low | accept | First-party Microsoft test package; pinned to 10.0.9 matching the app |
</threat_model>
