Create-form image state = `hasImage`, `originalImageData` (base64|null, new upload only), `croppedImageData` (base64|null, new upload or re-crop).
1. File input onChange(file): `isGifFile(file)` -> skip crop (originalImageData = base64(file), croppedImageData = null, hasImage = true, show GIF notice) after the 5MB gate; else -> `<ImageCropModal file={file} aspectW={4} aspectH={3} title="Crop Location Image" onSave onClose />`.
2. New-upload onSave(originalFile, croppedBlob) -> originalImageData = base64(originalFile), croppedImageData = base64(croppedBlob), hasImage = true.
3. Re-crop -> fetch the retained `/original` (or the local originalImageData if unsaved) -> ImageCropModal; onSave sets only croppedImageData (IMG-02).
4. Remove -> clear all three.
5. Preview `<img>`: local croppedImageData -> data URL; else if hasImage -> `getImageUrl('global-location', createForm.id, 'cropped')`; else placeholder.
6. Global create payload includes `hasImage`, `originalImageData`, `croppedImageData` (drop `imageBase64`).
</crop_site_wiring_contract>
