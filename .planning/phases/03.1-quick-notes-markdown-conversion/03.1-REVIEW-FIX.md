## Fixed Issues

### WR-01: Quick Notes textarea can visually collapse to 0px height after switching sessions

**Files modified:** `src/client/components/tabs/SessionLog.jsx`, `src/client/components/markdown/MarkdownField.jsx`
**Commit:** 7fb1dbe
**Applied fix:** Added `key={session.id}` to `<MarkdownField>` in `SessionLog.jsx` so it remounts on session switch, matching the sibling `RichTextEditor`. Also hardened `useAutoGrow` in `MarkdownField.jsx` to bail out when the textarea's `offsetParent` is `null` (i.e. hidden), preventing `scrollHeight` from being measured as `0` and pinning the inline height.

### WR-02: Formatting toolbar can get stuck disabled when the container crosses the responsive breakpoint

**Files modified:** `src/client/components/markdown/MarkdownField.jsx`
**Commit:** a9e1935
**Applied fix:** Added a `useIsSplitView` hook backed by `ResizeObserver` that tracks whether the field's container is currently rendering the CSS-driven split view (>= 480px, non-`forceTabs`). `toolbarDisabled` is now `!isSplitView && activeTab !== 'edit'`, so the toolbar stays enabled whenever the edit pane is actually visible, regardless of stale `activeTab` state.
**Note:** This is a logic/behavioral fix (new hook, new derived state) — flagged below as requiring human verification since automated syntax checks cannot confirm the `ResizeObserver` callback fires correctly across all container-resize scenarios in the browser.

### WR-03: `remarkGfm` tables render with no visual styling

**Files modified:** `src/client/index.css`
**Commit:** ffeed94
**Applied fix:** Added `.markdown-preview table`, `.markdown-preview th`/`td`, and `.markdown-preview thead th` rules matching the review's suggested styling (borders, padding, amber header background) consistent with the existing dark theme.

### WR-04: Quick Notes hint text overstates what's captured automatically

**Files modified:** `src/client/components/tabs/SessionLog.jsx`
**Commit:** 7bfad05
**Applied fix:** Changed the hint copy from "DC button clicks are logged here automatically." to "Click ★ Save on any Toolkit result to log it here." to accurately describe the manual save action required.

### IN-01: Quick Notes field has no accessible label

**Files modified:** `src/client/components/markdown/MarkdownField.jsx`, `src/client/components/tabs/SessionLog.jsx`
**Commit:** bca7f15
**Applied fix:** Added an `ariaLabel` prop to `MarkdownField`, forwarded to the internal `<textarea>` as `aria-label`. `SessionLog.jsx` now passes `ariaLabel="Quick notes"` to the Quick Notes instance.

### IN-02: `forceTabs` CSS restates base rules verbatim instead of disabling the container query

**Files modified:** `src/client/index.css`
**Commit:** 6b797a3
**Applied fix:** Scoped the `@container mdfield (min-width: 480px)` selectors with `.markdown-field:not(.markdown-field-force-tabs)` and removed the duplicate `.markdown-field-force-tabs` override block entirely, so the base single-column rules are now the single source of truth for the "tabs" layout.

### IN-03: Heading levels 4-6 and `<hr>` fall back to unstyled browser defaults in markdown preview

**Files modified:** `src/client/index.css`
**Commit:** 934e45f
**Applied fix:** Added `.markdown-preview h4, h5, h6` (amber, slightly smaller than h3) and `.markdown-preview hr` (themed border color) rules consistent with the existing heading scale.
