## Sampling Rate

- **After every task commit:** Manual smoke check in the browser (`npm run dev`) — type sample markdown into Quick Notes, confirm the tab toggle stays visible at any browser width (including maximized/ultrawide), confirm preview renders, confirm toolbar buttons work.
- **After every plan wave:** Re-verify Quick Notes plus a quick spot-check of one other existing `MarkdownField` site (e.g. Overview & Hook) to confirm zero regression from the `forceTabs` prop addition and new CSS rules.
- **Before `/gsd-verify-work`:** Full conversational UAT covering all 3 phase success criteria.
- **Max feedback latency:** immediate (manual browser check, no test suite to wait on)
