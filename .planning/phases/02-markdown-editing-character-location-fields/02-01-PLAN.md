## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering / Information Disclosure | MarkdownPreview / react-markdown rendering | medium | mitigate | Use react-markdown default rendering (AST → React elements, NO `dangerouslySetInnerHTML`); do NOT add `rehype-raw`. If raw HTML passthrough is ever needed later, `rehype-sanitize` must be added in the same change. Not needed for this phase's plain-prose scope. |
| T-02-02 | Tampering | Markdown link rendering (remark-gfm autolinks) | low | mitigate | Leave react-markdown's default `urlTransform` in place (neutralizes `javascript:` and other unsafe URL schemes). Do not override it with a permissive transform. |
| T-02-SC | Tampering | npm installs (react-markdown, remark-gfm, remark-breaks, strip-markdown) | high | mitigate | All four packages verified OK in RESEARCH.md Package Legitimacy Audit (registry existence, publish history, non-deprecated, no suspicious postinstall, remarkjs-org source).
